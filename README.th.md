# TubeKit — เครื่องมือฟรีช่วยครีเอเตอร์ YouTube

**▶ ใช้งานได้เลยที่: https://ronsuthlor3-lab.github.io/tubekit/**

[English](README.md)

ช่วยให้ **คนดูจริง** เพิ่มขึ้น ด้วยการทำคอนเทนต์และหน้าปกให้ดีขึ้น — **ไม่มีบอทปั่นวิว**
วิวปลอมผิดกฎ YouTube ถูกตัดทิ้ง และทำให้ช่องโดนลดการมองเห็นหรือแบน

ทำงานในเบราว์เซอร์ทั้งหมด วิดีโอและไฟล์ **ไม่ถูกอัปโหลด** ฟรี ไม่ต้องสมัคร

## 5 เครื่องมือ

| | ทำอะไร | ต้องใช้อะไร |
|---|---|---|
| 📊 **วิเคราะห์ช่อง** | หา "เพชรที่ซ่อนอยู่" (คนดูนานแต่ YouTube แสดงน้อย), คลิปที่ควรแก้ภาพปก/ชื่อ (เห็นเยอะแต่คลิกน้อย), วันที่ลงคลิปแล้วได้ผลดี | ไฟล์ CSV ที่ส่งออกจาก YouTube Studio (โหมดขั้นสูง) |
| 🖼️ **ภาพปก + ชื่อ** | ดูภาพปกในหน้าแรก มือถือ และคลิปแนะนำขนาดเล็ก ธีมสว่าง/มืด เทียบกับคู่แข่ง ตรวจขนาด สัดส่วน ความรก ความต่างสี ความยาวชื่อ | รูปภาพปก |
| ✂️ **ทำ Shorts** | หาช่วงเด่นจากเสียง ครอปแนวตั้ง 9:16 (หรือภาพเต็ม + พื้นเบลอ) ใส่ข้อความหัวคลิปและฝังซับไทย ได้ไฟล์ 720×1280 | ไฟล์วิดีโอ + (ไม่บังคับ) ไฟล์ซับ |
| 📝 **ซับ + Chapters** | อ่านซับอัตโนมัติของ YouTube ล้างแท็กและบรรทัดซ้ำ แก้ข้อความ รวมบรรทัดสั้น ทำบทบรรยาย แนะนำ chapters และตรวจตามกฎ YouTube | ไฟล์ซับ .srt/.vtt/.sbv จาก Studio |
| 💬 **คอมเมนต์ที่ยังไม่ตอบ** | รวมคอมเมนต์ที่ช่องยังไม่ตอบ คำถามขึ้นก่อน ข้อความตอบสำเร็จรูป กดไปตอบบน YouTube | YouTube Data API key ของคุณเอง (ฟรี) |

## ข้อจำกัดที่ควรรู้

- **วิเคราะห์ช่อง:** ชื่อคอลัมน์ของ Studio เปลี่ยนตามภาษาและเมตริกที่เลือก ระบบจับให้อัตโนมัติ (ไทย/อังกฤษ) และแก้เองได้ จุดที่คนกดออกจากคลิปไม่อยู่ในไฟล์ส่งออก ต้องดูใน Studio
- **ทำ Shorts:** อัดแบบเรียลไทม์ในเบราว์เซอร์ คลิป 60 วินาทีใช้เวลา 60 วินาที ต้องเปิดแท็บไว้จนเสร็จ ได้ไฟล์ WebM เป็นหลัก ซึ่ง YouTube รับปกติ ใช้ Chrome หรือ Edge บนคอมจะดีที่สุด การหาช่วงเด่นดูจากเสียงอย่างเดียว คุณต้องเลือกช่วงเองเป็นคนสุดท้าย
- **ซับ:** การถอดเสียงไทยด้วย AI ในเบราว์เซอร์ยังแม่นไม่พอ เลยใช้ซับอัตโนมัติของ YouTube เป็นวัตถุดิบ
- **คอมเมนต์:** ต้องกดตอบที่ YouTube เอง เครื่องมือไม่โพสต์แทนคุณ API key เก็บในเบราว์เซอร์และส่งไปที่ googleapis.com เท่านั้น ถ้ามีคำตอบเกิน 5 ข้อในเธรดเดียว ระบบอาจนับว่ายังไม่ได้ตอบ
